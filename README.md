# Stack-Based Expression Evaluator (DCOMP320)

## Overview
This program reads mathematical expressions from `input.txt`, evaluates them using a LIFO Stack data structure, and writes results to `output.txt`.

## How to Run
1. Place `input.txt` in the root folder.
2. Run `python main.py`.
3. View evaluated expressions in `output.txt`.

## Assumptions & Limitations
- Supports `+`, `-`, `*`, `/`, and nested parentheses `()`.
- Follows standard BODMAS precedence rules.
